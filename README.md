# Research Provenance Card (RPC)

Research Provenance Card is a version-bound, machine-readable provenance record for research outputs with AI contribution.

It captures who did what (human and AI actors), what evidence exists, and whether claims were independently attested or reproduced.

The project provides:
- RPC v0.1 human-readable specification
- JSON Schema for card validation
- CLI tools for validation, reference resolution checks, and journal disclosure generation
- Registry layout and static site builder for provenance panels

This repository is an implementation profile aligned with emerging AI disclosure standards in research.
