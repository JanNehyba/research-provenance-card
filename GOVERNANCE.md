# Governance

This project is maintained as an open, standards-oriented repository.

## Maintainer Model
- Initial maintainer: Jan Nehyba.
- Contributions are reviewed through pull requests.
- Normative changes to schema/spec require explicit versioning impact notes.

## Decision Rules
- Backward-incompatible schema change: requires new schema version.
- New enum value: requires changelog entry and migration note.
- Tooling behavior that may affect interpretation of evidence must be documented before merge.
