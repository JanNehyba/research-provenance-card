## 6. Limitations

- **Screener independence is partial.** Both screeners are the same model family working from differently worded criteria. Their agreement measures prompt stability more than it measures independent judgement. The human sample is the corrective, not the kappa between them.
- **Grey literature was not searched systematically.** Publisher author instructions, citation style manuals and institutional policies are in scope by type and enter only when a searched record points at them.
- **PDF extraction loses table structure.** A dimension stated only inside a table may have been missed, and a quote taken from one may have failed verification although the text is really there.
- **Semantic Scholar was not used**, because it rate-limits without an API key. Its coverage of computer science conference proceedings is better than Crossref's, so some HCI work may be missing.
- **One snowballing iteration.** A scheme cited only by papers two steps from the included set would not be reached.
